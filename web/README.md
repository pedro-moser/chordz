# chordz web frontend

SvelteKit app consuming the Rust core via WebAssembly. The `$wasm` vite alias
points at `web/pkg`, which is generated by `wasm-pack` — build it first or the
dev server has nothing to import.

```sh
# from the repo root
wasm-pack build --target web --out-dir web/pkg --no-default-features --features wasm

cd web
npm install
npm run dev
```

Checks: `npm run check` (svelte-check) · `npm run test` (vitest).

Production build: `./build.sh` (from the repo root: `web/build.sh`) — builds
the WASM package and the Svelte app; output lands in `web/build/`.

Note: `src/wasm.d.ts` is a hand-written ambient module declaration that
shadows the generated `chordz.d.ts`. New WASM exports must be added there too,
or `npm run check` fails.
